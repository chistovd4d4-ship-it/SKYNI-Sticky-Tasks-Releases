# LinkedIn post draft (English)

I’m preparing the first public product from SKYNI Labs: **SKYNI Sticky Tasks**, a free beta for Windows.

It keeps quick tasks on real, independent sticky-note windows. Each note has its own list, color, position, and Always on Top setting. Notes are stored locally on the PC; there’s no account or cloud sync.

The first beta is still going through final hands-on acceptance, so downloads are not available yet. If you try it when the beta opens, I’d value practical feedback on everyday use and Windows compatibility.

More details: https://github.com/chistovd4d4-ship-it/SKYNI-Sticky-Tasks-Releases
