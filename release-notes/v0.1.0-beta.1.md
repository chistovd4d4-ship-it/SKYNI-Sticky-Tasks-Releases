# SKYNI Sticky Tasks v0.1.0-beta.1

**Prerelease draft — not published.**

SKYNI Sticky Tasks is a free Windows beta for quick tasks on independent paper-like sticky windows.

## Highlights

- Multiple independent stickers with separate task lists.
- Yellow, pink, and blue paper styles; movable and resizable windows.
- Complete, edit, and remove tasks.
- Per-sticker Always on Top and frame settings.
- Local-only storage, JSON import/export, and backup recovery.

## Downloads planned

- `SKYNI-Sticky-Tasks-Portable.exe`
- `SKYNI-Sticky-Tasks-Setup.exe`
- `SHA256SUMS.txt`

Files are intentionally not attached. The beta remains subject to final user acceptance. Both Windows packages require Microsoft Edge WebView2 Evergreen Runtime; the installer can bootstrap the runtime online if permitted. The executables are unsigned and may be blocked by device policy.

## Privacy

Notes remain in the local Windows user profile. No account or cloud synchronization is provided.

## Feedback

Please report the Windows version, WebView2 runtime status, and steps to reproduce a problem. Do not include private notes or logs that may contain them.
