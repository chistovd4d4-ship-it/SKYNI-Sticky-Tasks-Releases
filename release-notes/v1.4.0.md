# SKYNI Sticky Tasks Web v1.4.0

## English

- Reorder tasks inside a sticker with drag and drop, keyboard controls, or the task menu. Order persists across reload and JSON export/import.
- Due dates use the local calendar. Tasks due in 1–4 days are amber; unfinished tasks due today or earlier are red. Completed and undated tasks keep their normal color.
- Recovery backup controls are in Settings beside JSON export/import. A verified local backup is created before an import replaces data. Valid backups show their creation time and can be downloaded or restored after confirmation.
- The Settings scrollbar is thin (5 px), rounded, and low contrast, with colors for Light/Dark/System. Native wheel, touch, and keyboard scrolling remain available.
- Existing IndexedDB content and attachments, JSON compatibility, PWA updates, and detached sticker windows remain supported.

The Settings scrollbar change applies only to the Web dialog. Windows uses a separate settings menu and is unaffected; no Windows worktree files were changed.

## Русский

- Переставляйте задачи внутри стикера перетаскиванием, клавиатурой или через меню. Порядок сохраняется после перезагрузки и в JSON экспорте/импорте.
- Сроки учитывают локальный календарь. Задачи за 1–4 дня выделяются янтарным; невыполненные задачи на сегодня и ранее — красным. Выполненные задачи и задачи без срока сохраняют обычный цвет.
- Управление резервной копией доступно в настройках рядом с экспортом/импортом JSON. Перед заменой данных создаётся проверенная локальная копия. У валидных копий отображается дата и время; их можно скачать или восстановить после подтверждения.
- Полоса прокрутки настроек тонкая (5 px), скруглённая и ненавязчивая; цвета учитывают Light/Dark/System. Сохранены wheel, touch и клавиатурная прокрутка.
- Сохранены IndexedDB данные и вложения, совместимость JSON, обновление PWA и отделённые стикеры.

Изменение scrollbar относится только к диалогу Web. В Windows используется отдельное меню настроек, поэтому оно не затронуто; файлы Windows worktree не изменялись.
